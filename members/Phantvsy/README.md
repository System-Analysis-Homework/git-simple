# 我的 Git 学习笔记
## 第一次 Git 实验总结
1. `git add` 的作用是：把工作区的修改添加到暂存区，标记这些文件准备参与下一次提交。
2. `git commit` 的作用是：将暂存区里保存的改动保存到本地版本库，生成一条新的提交快照，记录版本。
3. 本次实验中 `git restore notes.md` 的作用是：撤销工作区还没有加入暂存的修改，把文件恢复到暂存区或者最近一次提交的状态。
4. `commit` 与 `push` 的区别是：commit 仅在自己的本地电脑生成版本记录，不会传到网上；push 将本地已经完成的提交上传推送到远程 GitHub 仓库。
